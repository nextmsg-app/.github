## NextMsg

**The one-way messenger for AI agents, scripts and servers.** Send a push to your phone with one HTTP request. No bots, no chat apps, no account.

```sh
curl -d 'Deploy finished' https://api.nextmsg.app/p/$NEXTMSG_KEY
```

- 🤖 **MCP server:** [`@nextmsg/mcp`](https://github.com/nextmsg-app/mcp) gives Claude, Cursor, Codex, Antigravity and other agents a `notify_human` tool ([npm](https://www.npmjs.com/package/@nextmsg/mcp))
- 📚 **Guides:** [GitHub Actions](https://nextmsg.app/guides/github-actions), [cron jobs](https://nextmsg.app/guides/cron-jobs), [servers](https://nextmsg.app/guides/server-alerts), [AWS](https://nextmsg.app/guides/aws), [Claude Code](https://nextmsg.app/guides/claude-code), [Cursor](https://nextmsg.app/guides/cursor), [Codex](https://nextmsg.app/guides/codex), [Antigravity](https://nextmsg.app/guides/antigravity)
- 📱 **Apps:** Android and iOS, coming soon. Free for 100 messages a month; Pro is a one-time purchase.
